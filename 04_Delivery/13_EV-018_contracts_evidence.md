# EV-018 — Contracts and SDK generation evidence

Date: 2026-11-03. Branch: `claude/vigilant-heisenberg-uoozxp`. Status: EV-018 complete.

**Done when:** OpenAPI and the TypeScript SDK are generated from validated schemas.

## Design

- `packages/contracts` holds the source of truth. It contains strict Zod schemas (`z.strictObject`), so undocumented fields fail validation:
  - `Meta`, `ErrorCode`, `ErrorEnvelope`;
  - health: `LiveStatus`, `ReadinessCheckResult`, `ReadinessReport`, `LiveResponse`, `ReadinessResponse`;
  - a route registry listing every endpoint with every status code it returns.
- OpenAPI 3.1 is generated by Zod 4's built-in `z.toJSONSchema` (JSON Schema 2020-12, which OpenAPI 3.1 uses). No extra generator library is involved. The output is deterministic and committed as `packages/contracts/openapi.json`.
- `packages/sdk` holds TypeScript types generated from `openapi.json` by openapi-typescript 7.13.0, committed as `src/schema.ts`. `createEvoneClient({ origin })` wraps openapi-fetch 0.17.0 and prefixes `/api/v1`. Types are compile-time only; responses are not re-validated at runtime.
- The API types its responses with the contract types. Its local envelope types were removed, so there is now one definition.

## Known risks

- **openapi-typescript 7.13.0 declares a TypeScript `^5` peer dependency**, and the workspace uses 6.0.3 (`pnpm peers check` reports it). Generation and type-checking work today, but the combination is unsupported upstream. Revisit when openapi-typescript supports TypeScript 6, or pin a TypeScript 5 for generation only if it breaks.
- **ESLint 9.39.5 is now marked deprecated** by npm. EV-009 pinned 9.x for Next.js lint-plugin compatibility. Upgrading needs a separate task that re-checks `eslint-config-next`.
- The SDK does not validate responses at runtime. Clients that must not trust the API (none yet) should parse with the `@evone/contracts` schemas.
- The route-coverage test reads Express 5's internal `router.stack`. An Express major upgrade could change it; the test would then fail loudly rather than pass silently.
