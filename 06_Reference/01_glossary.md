# Glossary — Product, EV and Engineering

| Term | Meaning |
|---|---|
| EV | Electric vehicle |
| BEV | Battery electric vehicle |
| kWh | Unit of energy/battery capacity |
| kW | Unit of power/charger rating |
| SOH | State of Health of battery, only meaningful with testing method and source |
| SOC | State of Charge; **not** the same as SOH |
| AC/DC charging | Alternating / direct current charging with distinct power and plug types |
| Claimed range | OEM-provided distance under stated test cycle, not real-world guarantee |
| Variant | Exact trim/powertrain/version of EV model |
| CPO | Charge Point Operator (provider of charging infrastructure/service) |
| PostGIS | PostgreSQL geospatial extension |
| JWT/JWKS | Access token and public key set used to verify signed claims |
| RBAC | Role-based access control, supplemented by resource/tenant checks |
| DTO | Validated transport object used by API |
| PII | Personally identifying information |
| RPO/RTO | Recovery point / recovery time objectives |
| LSP/DLA | Lending Service Provider / Digital Lending App under applicable RBI framework |
| IRDAI | India's insurance regulator |
| DPDP | India's Digital Personal Data Protection framework |
| Outbox | DB-persisted event dispatch mechanism |
| Idempotency | Repeat request/event produces the same business result without duplicate side effects |
| MVP | Smallest viable product to test demand and product behavior |
| UAT | User acceptance testing |
| Liquid Glass | Translucent layered visual effect; used selectively as UI design inspiration |
