# Used EV Marketplace Operations: Dealer Onboarding, Verification and Support

## Individual seller onboarding
1. User signs up and verifies channel/contact via managed auth.
2. Creates listing draft, model/variant, location, condition/ownership notes, photos.
3. Submits for moderation; receives a clear review status.
4. Moderator checks spam, duplicates, trademark/photo rights, price anomalies and unsafe claims.
5. Approve with audit or reject with actionable reason. Vehicle stays unpublished until approved.
6. Enquiries routed with explicit buyer contact-sharing consent; seller can mark sold.

## Dealer onboarding
Manual dealer organisation request, legal trading name, city, business contact, admin review. Dealer owner can invite staff only after approval. 'Verified Dealer' should state **what was verified** and date/expiry; it does not verify every listing or battery. Set dealer SLA/response expectations and fraud-report handling.

## Listing moderation rubric
| Check | Action if failed |
|---|---|
| Product is actually EV and exact variant mapped | hold until resolved |
| Photos match listed vehicle; no stolen stock photos/PII | request replacement |
| No invented battery certificate, service record, accident claim | remove claim or obtain evidence |
| Asking price plausible but does not guarantee fair price | flag for manual check, not forced valuation |
| Seller profile/contact verified to appropriate scope | pause publication if required |
| Duplicate/spam listing | reject or merge after review |
| Misleading 'new launch' model information | refer catalogue editor |

## Fraud complaint escalation
Buyer complaint → ticket with listing ID → immediate hide if serious allegation pending review → contact seller and request corroboration → decision/audit → user notification. Preserve lawful evidence under retention policy; no public accusations without fact-checking.

## Enquiry quality operations
Track acknowledged vs unacknowledged leads, spam reports and seller responsiveness. Set contact visibility only after explicit user action. No scraping/export of all buyer numbers. Sellers can block abusive contacts and close sold listings.

## Support queues
Marketplace disputes, access/privacy requests, payments and accessories, map errors, news corrections, partner contact complaints. Define SLA internally; public guarantees only after staffing to honor them.
